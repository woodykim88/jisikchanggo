# 지식창고

블로그·Threads 채널의 글감을 데이터로 고르기 위한 키워드 조사 기록.

- [글감조사_파이프라인.md](글감조사_파이프라인.md): 조사 순서·점수·채널 연결 규칙
- [키워드리스트.md](키워드리스트.md): 날짜별 글감 TOP 10과 채널별 배분
- `조사데이터/`: 키워드 조회 원자료(10/21부터 네이버 검색광고 API 월간 검색수, 그 전은 카카오 키워드 플래너)
- `hints/`: 채널별 소재 JSON (`scripts/sync_hints.py`가 각 봇 저장소로 보냄)

재료일 뿐 의무가 아니다. 각 채널의 성격과 방향이 우선이다.
